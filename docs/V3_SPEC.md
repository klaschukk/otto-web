# Otto.web v3 — ТЗ

Цель: сайт студии выглядит как премиальная студия, а не как фрилансер с шаблоном. Владелец салона за 10 секунд понимает: «эти сделают мне сайт, которого нет у конкурентов», за 30 секунд видит цену, за минуту звонит.

## 1. Концепция: «Сайтове, които звънят»

Мы продаём не сайт, а **звонки**. Вся страница доказывает одну мысль: сайт от Otto.web приводит клиентов.

- **Голос:** короткий, уверенный, конкретный. Без «иновативни решения». Пример: «Хората ви търсят в Google в 21:40. Сайтът ви отговаря вместо вас.»
- **Визуальная система** (развитие v2, не замена):
  - тёмная сцена `#0e0f11` в первом экране и в шоуриле, светлая бумага `#f6f5f1` в остальных секциях;
  - один акцент — жёлтый маркер `#ffe24a`; второго акцента нет;
  - шрифты: Onest (заголовки, 800, плотный трекинг −0.03em), IBM Plex Mono (цифры, цены, метки);
  - крупная типографика: h1 до 7.5rem на десктопе, текст до 62ch.
- **Подпись студии:** везде, где есть цифра, она набрана моноширинным шрифтом на жёлтом маркере. Это «почерк» Otto.web.

## 3. Главная, по секциям

1. **Hero, тёмный, во весь экран (но не 100vh, по контенту).**
   - h1: «Сайтове, които <mark>звънят</mark>.»
   - Под ним одна строка: «Правим сайтове за малък бизнес в Бургас. Всеки е различен. Първо виждате вашия, после плащате.»
   - CTA: «Покажете ми пример» (скролл к работам) и телефон моноширинным.
   - **Анимация-доказательство:** справа телефон в рамке, на экране демо-сайт. Поверх него каждые ~3 секунды всплывают уведомления: «📞 Ново обаждане от сайта · 21:40», «Viber: Искам час в събота», «Маршрут към вас · 3 км». Это не эмодзи-декор, а UI-карточки уведомлений с иконками SVG.
2. **Бегущая строка ниш** (marquee, моно): автосервизи · салони · зъболекари · барбершопи · ресторанти · хотели. Медленная, остановка при hover, отключается при `prefers-reduced-motion`.
3. **Шоурил работ — горизонтальный скролл с пином (GSAP ScrollTrigger).**
   - Секция закрепляется, вертикальный скролл двигает ленту из 4 демо вбок.
   - Каждое демо: большой телефон со скриншотом, слева название и **одна фишка** («Калкулатор на цена», «Свободни часове днес», «Палитра гел лакове», «Карта на зъбите»).
   - На мобильном пина нет: обычный свайп-карусель со snap.
4. **«Без шаблони»** — 4 блока «идея → фишка», связанные с шоурилом. Текст: «Автосервизът продава доверие → калкулатор, който казва цената преди ремонта.»
5. **До / След — слайдер.** Слева карточка бизнеса в Google Maps без сайта, справа тот же бизнес с сайтом. Ручка тянется пальцем.
6. **Как става** — таймлайн «Ден 0 / Ден 1–2 / Ден 3 / Ден 4». Линия прорисовывается при скролле (SVG stroke-dashoffset).
7. **Цени** — чек-ценоразпис из v2 (это работает, оставить). Добавить блок «Хостинг» (см. §6).
8. **Кой стои зад Otto.web** — Кирил, фото, 3 строки, цифры проектов (prevozni ~350 посетители на ден).
9. **FAQ.**
10. **Финальный CTA, жёлтый экран:** «Да направя пример за вашия бизнес?» + форма из 3 полей (име, бизнес, телефон) + Viber/WhatsApp.

## 4. Анимации (бюджет и правила)

- Библиотеки: **GSAP 3 + ScrollTrigger** с cdnjs (`gsap/3.12.5`). Больше ничего: Lenis, three.js и параллакс не нужны.
- Ровно три «момента»: уведомления в hero, пин-шоурил, прорисовка таймлайна. Всё остальное — лёгкий reveal (opacity + y 16px, 350 мс, `power2.out`, stagger 60 мс).
- Анимируются только `transform` и `opacity`. Никаких анимаций ширины, высоты или `top`.
- `prefers-reduced-motion: reduce` → всё сразу в конечном состоянии, пина нет.
- Контент виден без JS: reveal-классы добавляются через JS, а не стоят в HTML.
- Бюджет: LCP < 2.0 с на 4G, JS < 80 KB (GSAP + ScrollTrigger ≈ 70 KB gz). Картинки только WebP с width/height.

## 5. Стек (как у prevozni)

```
app/
  __init__.py      create_app(), конфиг из .env
  routes.py        страницы, i18n по префиксу /en /ru
  leads.py         POST /api/lead → SQLite + уведомление в Telegram
  admin.py         /admin: список заявок, статус, экспорт CSV
  i18n/            bg.yaml, en.yaml, ru.yaml (тексты, не код)
  templates/       base.html + страницы + partials
  static/          css/, js/ (main.js, gsap с cdnjs), img/, shots/
custom/<slug>/     ручные демо (как сейчас), отдаются как статика под /demo/
data/otto.db       заявки (в .gitignore)
tests/             pytest: все страницы 200, форма пишет в БД, honeypot режет ботов, /admin требует логин
Dockerfile         python:3.13-slim, gunicorn 2 воркера
docker-compose.yml app (gunicorn :8000) + nginx (:8080 сейчас, 80/443 через Cloudflare после домена)
.github/workflows/ ci.yml: pytest на каждый push; deploy.yml: по тегу — ssh на сервер, git pull, docker compose up -d --build, curl /health
```

- Flask 3, Jinja2, gunicorn, SQLite. Без ORM: 1 таблица `leads(id, ts, name, business, phone, source, status)`.
- Форма: honeypot-поле + лимит 5 заявок с IP в час. Telegram-бот: токен и chat_id в `.env`.
- `/health` отдаёт `ok` и версию (git sha).
- SEO: `hreflang` bg/en/ru, sitemap, OG-картинка 1200×630, schema.org `ProfessionalService`.
- Аналитика: self-hosted Umami, как на других сайтах. Не GA.

Это одновременно **DevOps-кейс для CV**: Docker Compose, CI/CD через GitHub Actions, healthcheck, бэкап `data/otto.db` по cron. Каждый шаг Кирилл делает в LEARNING MODE: объясняем, он набирает команды.

## 6. Хостинг клиентских сайтов и модель денег

**Клиентские сайты не кладём на свой сервер.** Если сервер упадёт, лягут все клиенты разом, а ты отвечаешь за чужой бизнес 24/7.

| Что | Где | Сколько стоит тебе |
|---|---|---|
| Статический сайт клиента (визитка, бизнес) | **Cloudflare Pages** на аккаунте клиента (или на аккаунте Otto с передачей) | 0 € — бесплатно, HTTPS и CDN включены |
| Домен клиента | регистратор на имя клиента | клиент платит ~10–15 € в год сам |
| Форма или запись на час | Cloudflare Pages Functions или наш общий `/api/lead` на сервере Otto | 0 € |
| Сайт студии Otto.web + заявки | твой VPS (Docker) | уже оплачен |

Деньги:
- **Разово:** сайт (79 / 149 / 249 €).
- **Ежемесячно, по желанию:** «Грижа за сайта», 15 €/мес: правки до 30 мин, обновление цен и фото, отчёт о посещениях раз в месяц, проверка, что всё работает. Хостинг для клиента бесплатный в любом случае, поэтому подписка честная: платят за твоё время, а не за «аренду».
- Цель: каждый 2-й клиент на подписке. 10 клиентов на подписке = 150 €/мес стабильно.

Вопрос владельцу: премиальный вид плохо сочетается с ценой 79 €. Варианты: оставить 79 как «Старт» (быстрые первые деньги) или поднять до 99/179/299 после первых 3 клиентов. Пока оставляем как есть.
